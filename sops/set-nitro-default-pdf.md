# Set Nitro PDF as the Default PDF Viewer

Use these steps to make PDFs open in Nitro (Nitro Pro / Nitro PDF) by default instead
of Edge, Acrobat, or another app.

## Quickest way (from any PDF file)

1. Find any PDF file in File Explorer or on your Desktop.
2. **Right-click** it → **Open with** → **Choose another app**.
3. Select **Nitro Pro** (may appear as **Nitro PDF**) from the list.
4. Check **"Always use this app to open .pdf files"** (Windows 11: choose **Always**).
5. Click **OK**. PDFs will now open in Nitro from now on.

## Alternative: through Windows Settings (Windows 11)

1. Open **Settings** → **Apps** → **Default apps**.
2. Under **"Set a default for a file type,"** type **.pdf** in the search box.
3. Click the app currently shown for **.pdf**.
4. Choose **Nitro Pro** and click **Set default**.

## Windows 10

1. Open **Settings** → **Apps** → **Default apps** → **Choose default apps by file type**.
2. Scroll to **.pdf**, click the app currently listed next to it.
3. Select **Nitro Pro** from the list.

## If Nitro isn't in the list

Nitro may not be installed on your computer. Submit a ticket at
**https://support.capitalvacations.com** to request Nitro be installed, and note which
computer you're on. (IT Help Desk: 8am–10pm EST, 7 days a week.)
