# OpenVPN2 Client Setup Guide

How to set up and connect to the VPN for Capital Vacations systems. Get everything from
the company VPN portal — **do not download OpenVPN from openvpn.net or any other website.**

## 1. Access the VPN portal
Open a web browser and go to **https://openvpn2.capitalvacations.com**. Select
**"Sign in with SAML"** and log in using your company email credentials.
*(If you receive a security warning, select Advanced and proceed to the site.)*

## 2. Download the connection profile
Once logged in, select **"Connection Profile"** and download the VPN configuration file
to your computer.

## 3. Import the profile
Open the downloaded file — the OpenVPN client should launch and prompt you to import the
profile. If the OpenVPN client isn't installed on your computer, **submit a ticket at
https://support.capitalvacations.com** to have IT install it. Do not download it yourself
from openvpn.net.

## 4. Connect to the VPN
After importing the profile, open the OpenVPN client and select **Connect**.

## 5. Confirm the connection
A browser window may open confirming successful sign-in. Once confirmed, you can close it.
